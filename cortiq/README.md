# Cortiq

Site marketing de Cortiq, partenaire growth fractional pour startups early-stage.

Next.js 14 (App Router) + TypeScript + Tailwind CSS. Aucune dépendance externe au build (fonts système, pas de service tiers).

## Développement

```bash
npm install
npm run dev
```

## Pages

- `/` — page d'accueil
- `/offres` — les deux offres + audit growth 90 jours
- `/methode` — les 4 principes + le process interne en 7 étapes
- `/a-propos` — positionnement et cible
- `/contact` — formulaire de contact
